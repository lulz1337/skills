A request through an agent

One tool call, then a response. The 8-second loop shows order, not measured latency.

Static diagram. Each numbered arrow is one event.

  1. Client sends a request.
  2. API dispatches the agent.
  3. Agent calls the tool; the tool returns context.
  4. Agent replies to the API.
  5. API answers the client; the loop rests before repeating.
