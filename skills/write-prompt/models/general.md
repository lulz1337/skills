# General baseline and other models

Use clear task instructions and only the context required to act. Specify an output format or give an example when the shape matters. Keep source material distinct from instructions. Match the requested language; do not switch to English merely because a model is small or open-weights.

Do not assume tools, API settings, system-message access, or reasoning features. A prompt pasted into a chat must work as a single message unless the user requests another surface. Request conclusions and useful supporting evidence, not hidden chain-of-thought.

For a named model without a bundled route, find the publisher's official documentation or model card and check its prompting or chat-template guidance. A publisher-owned model repository can be an official source. Apply relevant guidance only after reading it; if unavailable, use this baseline and disclose the gap.
