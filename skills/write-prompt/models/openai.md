# OpenAI: official documentation route

Use the available OpenAI documentation skill when applicable. Search https://developers.openai.com/ or https://platform.openai.com/docs for the exact requested model's prompting guide and open the relevant official page.

Check task-relevant guidance on instruction placement, examples, tool use, reasoning, and output control. Do not apply an older model's reminders or context rules to all later models. Do not invent API parameters or include runtime settings as if prompt text configures them.

For a Codex target, consult its official documentation when needed to establish agent capabilities. Distinguish the application from the selected model and the API. Keep a single-message prompt usable without requiring system-message access or API configuration unless the user requests those surfaces.
