# Claude: official documentation route

Start at https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices or find its current official replacement. Follow links to the requested model's guidance; do not infer that one version's advice applies to all Claude models.

Check only what matters for the task: instruction clarity, document placement for long inputs, examples, and output control. Use XML or other structure when it improves clarity, not as mandatory decoration.

For Claude Code capabilities, use https://code.claude.com/docs/ and the target environment's known configuration. Do not assume the target has the author's tools, skills, or permissions. Keep system-message and API-setting advice separate from a prompt intended for pasting into an agent session.
